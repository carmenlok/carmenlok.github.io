  • 2026-11-08Cut wasted speech-synthesis work in JoyAI-VL-Interaction serving, JD's open real-time video interaction model (vLLM-Omni, PR #10033) · in full-duplex async-chunk serving, the orchestrator prewarmed a Code2Wav (speech decoder) request on every turn; a new per-model plugin hook skips that prewarm when the reply has no audio, so text-only turns no longer start a request that was always aborted

  • 2026-10-01Humming vs Marlin kernels on SM121, end-to-end benchmarks (vLLM, quantization SIG, PR #56997) · worked with Ant Group on the end-to-end comparison against Marlin that helped the Humming release: Humming runs level with Marlin and matches its accuracy
